# Hologram showcase films

A film of several maps, each rebuilt as a glowing Blender hologram from its own map file, with one of your combos
replayed inside it from the demo, followed by a short flash of the real footage of the same moment. The first film
made this way ("Ghost Arenas", 10 maps, 4:03, 4K60) is the reference; its lineup is
`docs/examples/hologram/lineup.json`. Tools: `tools/hologram/`. The hologram look is the same as the CTF-Bolt scene
of the making-of (`tools/makingof/holo.py`, docs/MAKINGOF.md).

## 1. Structure

Per map: **BUILD** (9 s, the map draws itself, glowing outlines first, then surfaces; its name card switches on)
-> **COMBO** (10 s: the seconds before the shot at 0.6x, the ball in slow motion, time freezes on the blast, the
victim is marked, the announcer's word lands) -> **FLASH** (up to 4 s of the real game, first person, with its own
sound). Intro and outro around it. Each map plays its own UT99 song (from the map file); no narrator.

## 2. Workflow

All work data lives in `output\work\hologram\` (or `UTDD_HOLO_WORK`).

1. **Pick the combos.** Scan the demos (`/frag-movie` scan) so `output\moments-all.json` and the `.rich.log` scans
   exist. Choose one combo per map by skill, not kill count (see CLAUDE.md). Write `output\work\hologram\lineup.json`
   (format: the example). Optional fields per map: `name` (display name, default = file name without the game type),
   `song` (when the map's own song is missing or silent), `hide` (HUD regions to blur in the real footage, see 4).
2. `python tools\hologram\prep_maps.py` converts each map (`tools\blender\ut_map.py`), checks the map version against
   the scan (flag bases), cuts the demo window (`tools\blender\demo_tracks.py`), measures the play area and writes
   `<key>\config.json`. Hand-tuned camera values in an existing config.json are kept.
3. `tools\hologram\Test-Frames.ps1` renders three small frames per map and a contact sheet: check camera, roof cut,
   framing before spending hours.
4. `tools\hologram\Render-Holo.ps1` renders all shots in 4K (2 Blender workers, resumable). About 1140 frames per map.
5. `tools\hologram\Record-Flashes.ps1` records the real-footage flashes (UT owns the screen).
6. `python tools\hologram\film_holo.py plan`, then `still N out.png` for style frames, then `audio`, `frames`
   (the long one, background) and `final` (mux + 1080p copy) -> `output\holo-showcase.mp4`.
7. `python tools\hologram\holo_thumbs.py` for the three thumbnails (the frames/crops in it are the reference film's;
   pick your own), then the rest of the publishing kit (title, description, tags).

## 3. On-screen type (second design, after the first was rejected)

The first cut used the making-of design system as is: amber chip plates with mono text, Anton for everything, filler
sentences ("N of my recorded matches were on this map", "Now the same moment, replayed from the demo file"), a stat
line. The author's verdict: it looked "generated by your average AI". The second design (`holo_type.py`):

- **One family, Bahnschrift** (a DIN that ships with Windows, variable weight 300..700 and width 75..100), so the type
  reads like the hologram's own instruments. Thin, widely tracked caps for titles and labels; bold condensed for map
  names and the announcer word. `y` is the cap top, so lines align by their capitals.
- **Hairlines and corner brackets instead of plates.** Colours: cold white, hologram cyan for labels and rules, amber
  only for what matters now (the current map tick, the frozen readout, the call word).
- **Map card**: big thin index numeral, a vertical hairline, game mode in small caps, the name, the file name small
  underneath, ten ticks above showing where this map sits in the film.
- **Replay HUD** top right: a tiny "DEMO REPLAY" label over 0.6× / SLOW MOTION / FROZEN.
- **Victim**: brackets close in on the blast, an elbow leader runs out to "FRAGGED" and the name.
- **Motion with intent**: letters switch on one by one with a hologram flicker; the call word locks in while a cyan
  and a red copy snap back onto it. Nothing just fades.
- **No filler**: no trivia counts, no sentences that explain what the picture already shows. Credits at the end
  in a two-column block (label | value), "KEEP UT ALIVE" as the sign-off.
- Show style frames (`film_holo.py still`) of every element before the full render.

## 4. Traps

- **Disk space**: a 4K PNG is ~6.6 MB, a 10-map film ~75 GB of frames. When the disk ran full mid-render, Blender
  wrote empty **and truncated** PNGs (0.7 MB files that are not empty), and the film assembly died 9000 frames in.
  A size check is not enough: verify every frame with PIL (`Image.open(p).verify()`), delete the bad ones and run the
  resumable render again. Moving finished shot folders to another drive and linking them back with
  `New-Item -ItemType Junction` works, but PowerShell 7's `Get-ChildItem -Recurse` does not follow junctions, and frames
  read from a USB drive slow the assembly (~100 frames/min, about 2.5 h for 4 minutes).
- **Real footage shows other players' names and chat.** A slur in a player name and crude chat lines reached the
  first cut. Check every flash frame by frame (the console top left, the centre messages, the blue kill messages
  under them) and blur them with `hide` in lineup.json: `[t0, t1, [x0, y0, x1, y1]]`, flash seconds, 1080p pixels.
  Thumbnails from real footage: crop the kill feed away.
- **The game's console fills the top left of the real footage**: the film's map label goes bottom left there.
- **Announcer word**: "<you> had a Double Kill" can follow a combo that hit one player (the first kill was earlier).
  The multi-kill word is used only when the combo itself has 2+ victims; else the server's call right before your
  last kill line; else "SHOCK COMBO!". `victim_names` in config.json is a joined string ("a, b"), not a list:
  `len()` of it counts characters.
- **ffmpeg audio graph**: input numbers must count inputs, not `-ss/-t/-i` arguments ("Invalid file index").
  `alimiter` raises the level back to the ceiling by default (`level=false` to really limit). Tracker songs start
  very quiet (one at -29 LUFS): `dynaudnorm` per song, then gain and a limiter: about -14 LUFS, true peak -1 dB.
- PowerShell variable names ignore case: a loop variable `$w` overwrote `$W` (the work folder) and the render did
  nothing.
- `drawtext` in some ffmpeg builds fails on Fontconfig; label check images with cv2 or PIL instead.
